# GitHub Primer Design Reference

Source:
https://primer.style/

## Purpose

Use GitHub Primer as the primary visual reference for Cold Lead Intake.

The app should feel:
- clean
- restrained
- professional
- information-focused
- suitable for a B2B productivity application

## Design principles

### Visual hierarchy
Prioritize the user's main task and primary information.
Avoid giving every element equal visual weight.

### Layout
Use generous whitespace and clear grouping.
Avoid unnecessary cards, borders, and decoration.

### Typography
Use a limited and consistent type hierarchy:
- page title
- section heading
- primary content
- secondary metadata

### Color
Use mostly neutral colors.
Use accent colors only for actions, status, warnings, and destructive actions.

### Forms
Use persistent labels.
Keep inputs visually consistent.
Group related fields together.

### Responsive design
The application must remain usable on desktop and mobile.
At narrow widths, prefer a simple single-column layout.

### Product character
The UI should resemble a modern developer/productivity tool rather than
a marketing website.

## Important

Use Primer as design inspiration and guidance.
Do not copy GitHub branding, logos, or reproduce Primer components exactly.
