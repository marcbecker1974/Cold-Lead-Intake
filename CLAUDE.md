# Cold Lead Intake App

# Purpose
A simple Web App for manually capturing cold b2b leads before later ressearch and qualification.  

# Tech Stack
HTML
CSS
Java Script

# How to run
Open Index.html in a browser

# Rules
Keep it simple
Do not add features unless requested
Company Name is required
All data must persists in localStorage
App must work at 375px and 1280px width
Prefer clear, maintainable code over clever solutions
